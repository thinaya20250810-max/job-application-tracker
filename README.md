# Job Tracker 📋

A simple and user-friendly web application designed to help users organize and track their job applications in one place.

## 🚀 Features

- Add new job applications using a form.
- Save application details using browser localStorage.
- Keep application data saved when the browser is closed and reopened.
- Organize and view submitted job applications.
- Track job application progress in one place.
- Simple and easy-to-use interface.

## 🛠️ Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling and layout.
- JavaScript – Application functionality and interactivity.
- LocalStorage – Storing application data in the browser.
- Git and GitHub – Version control and project management.

## 💻 Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or run the project using the Live Server extension.
4. Start adding and managing your job applications.
